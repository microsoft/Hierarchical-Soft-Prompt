## Security

Microsoft takes the security of our software products and services seriously, which
includes all source code repositories in our GitHub organizations.

**Please do not report security vulnerabilities through public GitHub issues.**

For security reporting information, locations, contact information, and policies,
please review the latest guidance for Microsoft repositories at
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).

<!-- END MICROSOFT SECURITY.MD BLOCK -->

Please report vulnerabilities with GitHub's private security-advisory workflow
for this repository. Do not place credentials, private data, exploit details,
or confidential artifacts in a public issue.

The repository must not contain datasets, checkpoints, generated predictions,
tokens, keys, passwords, connection strings, or local environment files.
